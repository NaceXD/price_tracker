# Price Tracker API

Асинхронный веб-сервис на **FastAPI** для автоматического отслеживания цен на авиабилеты с использованием **Travelpayouts (Aviasales) API v3**. Проект поддерживает многопользовательский трекинг одного маршрута (Many-to-Many), периодический опрос цен в фоне через **Celery Beat**, кэширование и защиту от брутфорса на базе **Redis**.

## 🚀 Стек технологий

*   **Backend:** Python 3.14+ / FastAPI / Pydantic v2
*   **Database & ORM:** PostgreSQL 16 / SQLAlchemy 2.0 (Async) / Alembic
*   **Task Queue:** Celery / Celery Beat / Redis 8
*   **Infrastructure & Testing:** Docker & Docker Compose / Pytest (Asyncio)

---

## 🛠️ Архитектура и Особенности

1.  **Оптимальная схема БД:** Маршруты между пользователями делятся через промежуточную таблицу `user_tracked_routes` (Many-to-Many). Если несколько человек следят за одним рейсом, рейс парсится один раз.
2.  **Безопасность API:** Документация Swagger (`/docs` и `/openapi.json`) скрыта от посторонних глаз с помощью **HTTP Basic Auth** и модуля `secrets`.
3.  **Защита от брутфорса и Лимитер:** Внедрен `ip_rate_limiter` (максимум 10 запросов в минуту с одного IP). При 5 неудачных попытках входа аккаунт временно блокируется в Redis на 15 минут.
4.  **Фоновые задачи:** Celery Beat каждые 5 минут инициирует опрос всех уникальных маршрутов из БД. Сами задачи выполняются асинхронно внутри воркеров через `asyncio.run`.

## 📦 Быстрый запуск через Docker Compose

Проект полностью контейнеризирован и готов к запуску одной командой.

### 1. Настройка окружения
Создайте в корне проекта файл `.env` и заполните его вашими данными:

```env
# База данных PostgreSQL
DB_USER=postgres
DB_PASSWORD=your_secure_password
DB_NAME=price_tracker

# Сервисы инфраструктуры
POSTGRES_HOST=postgres_db
REDIS_HOST=redis_cache

# Интеграция с API Aviasales
TRAVELPAYOUTS_TOKEN=your_travelpayouts_token_here

# Доступ к документации Swagger (Basic Auth)
DOCS_USERNAME=admin
DOCS_PASSWORD=super_secret_docs_password
```

### 2. Запуск контейнеров
Запустите сборку и старт всех сервисов (FastAPI, Celery Worker, Celery Beat, PostgreSQL, Redis):

```bash
docker-compose up --build
```

После успешного старта приложение будет доступно по адресу `http://localhost:8000`.

## 📡 Эндпоинты API (Краткий справочник)

### Авторизация (`/auth`)
*   `POST /auth/register` — Регистрация нового пользователя (создает связанный `Profile`).
*   `POST /auth/login` — Аутентификация через OAuth2 Form. Возвращает сгенерированный в Redis Bearer-токен (время жизни — 2 часа).
*   `GET /auth/users/me` — Получение профиля текущего авторизованного пользователя.

### Маршруты (`/routes`)
*   `POST /routes/track` — Добавить новый авиамаршрут для отслеживания (принимает `origin`, `destination`, `departure_date`). Сразу инициирует фоновый парсинг первой цены.
*   `GET /routes/{route_id}/prices` — Получить хронологическую историю изменений цен по конкретному маршруту.

## 🧪 Тестирование

Для тестирования используется изолированная база данных `tracker_test` (работает на порту `5433`, чтобы не затирать данные локальной разработки) и чистая база Redis.

### Запуск тестов внутри Docker:
```bash
docker-compose exec web pytest -v
```

Тестовое покрытие включает в себя:
*   Регистрацию и получение JWT-токена сессии.
*   Проверку защиты от брутфорса при подборе паролей (блокировка 423).
*   Проверку работы IP Rate Limiter (ограничение 429).
*   Валидацию прав доступа к документации Swagger UI.
*   Бизнес-логику совместного отслеживания маршрутов разными пользователями.
